# In-ear EEG classifier

Static page: the model runs in the browser (ONNX Runtime Web), preprocessing is a JS port of the
Python pipeline. Nothing here needs a build step or a server beyond static hosting.

- `index.html`, `app.js`, `worker.js`: the app (worker = Web Worker running preprocessing + inference)
- `about.html`: explanation page (research, model choice, pipeline, limits, privacy)
- `eeg.css`: styles for both pages
- `thumb.jpg`: painted thumbnail, generated by `tools/paint_thumb.py`
- `js/dsp.js`, `js/pipeline.js`: filters, STFT, chunking, vote (ported from `thesis/`)
- `js/coefficients.js`: generated scipy filter coefficients
- `models/inear_binary.onnx`: CNN-AttnS, binary (see Model below)
- `vendor/ort/`: vendored onnxruntime-web 1.22.0 (CPU/WASM backend)
- `tests/`: parity tests against Python reference output

## Model

CNN-AttnS, binary (healthy vs. pathological), the paper's best in-ear model. Source run:
`~/eeg/experiments/binary/in-ear/cnnattns-binary_wve/` (git 454c49e, ec+eo, focal loss), whose
10-fold means are the paper's Table "binary" row: chunk 77.0, subject 79.2, sens 79.9, spec 72.8.

Shipped checkpoint: `fold_5_best.pth`. Chosen among folds that trained normally (best validation
epoch >= 10; folds 2 and 4 peaked at epochs 6 and 2) and whose sensitivity/specificity trade-off
matches the paper's (sens above spec by a few points). Fold 5: chunk 79.5, subject 83.3, sens
81.6, spec 77.2; best epoch 36, early-stopped at 56. Every metric is within 0.7 std of the mean.
Runner-up: fold 3 (closest overall, epoch 22, but sens 75.8 < spec 78.5, the trade-off reversed).

## Regenerate model, coefficients and fixtures

Needs the thesis code (torch, scipy) plus `onnx`, `onnxruntime`, `onnxscript` on `PYTHONPATH`:

    python eeg/tools/export_onnx.py --code ~/eeg/code \
        --checkpoint ~/eeg/experiments/binary/in-ear/cnnattns-binary_wve/fold_5_best.pth

The script refuses checkpoints trained with a spectrogram cutoff other than 70 Hz, which is what
`js/dsp.js` assumes.

## Test
